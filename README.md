# Calculadora de Porcentagem

Projeto desenvolvido em Portugol Studio para cálculo de porcentagem.

## Funcionalidades

- cálculo de porcentagem
- desconto
- acréscimo

## Fórmula utilizada

(valor * porcentagem) / 100
